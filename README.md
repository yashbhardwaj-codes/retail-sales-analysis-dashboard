# 📊 Retail Sales Analysis Dashboard

## 📌 Project Overview

An interactive Retail Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, profitability, regional performance, product categories, and monthly sales trends.

## 🎯 Project Objectives

* Analyze total sales and total profit.
* Compare sales performance across different regions.
* Identify the most profitable product categories.
* Analyze the top 10 products by sales.
* Track monthly sales trends.
* Monitor important business KPIs.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## 📈 Dashboard Features

* **Total Sales:** Overall revenue generated.
* **Total Profit:** Overall profit generated.
* **Profit Margin:** Profit as a percentage of sales.
* **Total Orders:** Distinct order count.
* **Sales by Region:** Regional sales comparison.
* **Sales by Category:** Category-wise sales performance.
* **Profit by Category:** Category-wise profitability.
* **Top 10 Products:** Best-performing products by sales.
* **Monthly Sales Trend:** Month-wise sales analysis.
* **Interactive Filters:** Explore data by month and region.

## 💡 Business Value

This dashboard helps users understand sales performance, identify profitable categories, compare regional results, and monitor monthly trends to support data-driven business decisions.

## 🚀 How to Use

1. Download the Power BI `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Use the available filters to explore the dashboard.
